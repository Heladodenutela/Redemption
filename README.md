# Redemption

Juego de simulación de vida hecho en Processing 4. Eres un estudiante de primer semestre y tienes diez días para llegar bien a los parciales sin descuidar el sueño, los amigos, la familia ni el tiempo en el celular.

## Cómo jugarlo

1. Instala [Processing 4](https://processing.org/download).
2. En Processing, instala la biblioteca **Sound**: Sketch › Importar biblioteca › Gestionar bibliotecas › busca "Sound" › Install.
3. Descarga este repositorio (botón verde **Code** › **Download ZIP**) y descomprímelo.
4. Abre `Redemption/Redemption.pde` y dale ▶.

La carpeta tiene que llamarse `Redemption`, igual que el archivo `.pde`, o Processing no la abre. El juego crea solo la carpeta `partidas` la primera vez que guardas.
